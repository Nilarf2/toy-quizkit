# 封面与图标素材

本目录保留示例作品的封面、图标与可编辑源文件，不参与游戏运行。

- `cover.png`：1200 × 675，16:9 封面设计稿。
- `icon.png`：512 × 512，图标导出。
- `icon-300.png`：300 × 300，备用图标导出。
- `cover.svg` / `icon.svg` / `icon-300.svg`：可编辑矢量源文件。

视觉沿用游戏的米白、荧光绿和黑色，封面以原创牛、钢琴线索卡与放大镜表现“表情猜成语”，图标是戴侦探帽的笑脸放大镜。中文使用本机 Noto Sans CJK SC；PNG 已包含字体渲染，不需安装字体即可使用。所有图形均为原创矢量，不是页面截图。
